# Linear Vehicle Dynamics Simulator

A backend physics engine prototype designed to simulate longitudinal vehicle dynamics. This version focuses exclusively on straight-line physics, calculating real-time acceleration, velocity, and position based on engine torque, mass, and aerodynamic drag. It establishes the core architecture for a telemetry generation system, excluding lateral forces and differential mechanics.

## Tech Stack:

1. **Language:** Java 21

2. **Framework:** Spring Boot 4.0

3. **Build Tool:** Maven

4. **Utils:** Lombok

---

The code was fully commented for better understanding of anyone who wants to try in their own machine.
